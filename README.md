## 部署服务器并连接 SSH

登录后台后，点 Deploy → Deploy New Server，按顺序确认这几项：

1. **Choose Type**：个人用途选 Shared CPU，价格最低。
2. **Location**：选测过速的机房。
3. **Plan**：Cloud Compute 下从 5 美元档（vc2-1c-1gb）选起。
4. **Image**：Debian 或 Ubuntu。
5. **Additional Features**：不需要备份就关掉 Automatic Backups，每月省 1 美元。

SSH Keys、Firewall Group、Hostname 这些可选项没有特殊需求就保持默认，最后点右下角 Deploy 确认创建。

部署本身很快，但状态从 Installing 变成绿色 Running、系统能正常响应还需要几分钟。拿到 IP 后别急着连，等 5 分钟左右再操作。点进服务器详情页，把三样东西记下来：IP Address、Username（默认 root）、Password（页面带复制按钮）。同一页面上还能看到当月已用流量和已产生费用。

连接用 SSH 工具，Windows 上常用 Xshell：新建会话填 IP，第一次连接选择接受并保存密钥，用户名 root、密码填刚复制的，看到 root@vultr 这样的提示符就是连上了。

## 按小时计费：关机也在扣钱

Vultr 按小时计费，不是包月一次性扣。以 5 美元套餐为例，每小时扣 5 ÷ 30 ÷ 24 ≈ 0.0069 美元，从账户余额自动划走，Billing 页面随时能查余额和流水。

关键的一条：**关机不停止计费**。只要机器还存在于账户里，哪怕处于关机状态，小时费照扣。确定不用的机器，进服务器详情页点右上角的销毁（Destroy）按钮，删掉才停止扣费。很多人余额消耗得比预期快，原因就在这里。

## IP 连不上时，换 IP 的正确顺序

服务器 IP 出现大陆无法直连、海外访问正常的情况并不少见。Vultr 的处理方式很直接：重新开一台，就能拿到新 IP。但操作顺序有讲究——**先部署新服务器，确认新 IP 能用，再删掉旧机器**。

顺序反了会怎样：被删机器的 IP 会回到同机房的资源池，随机分配给下一个在这里开机器的人，也可能就是你自己。先删后开，有一定概率重新拿到那个连不上的 IP，白折腾一轮。

删之前可以先确认 IP 状态：用在线端口检测工具查这个 IP 的 22 端口，国内和国外的 TCP 检测都通才算正常。哪边不通，基本就是 IP 的问题，按上面的顺序换掉即可。这类有问题的 IP 放一段时间后有可能被解封，海外用户的连接则不受影响。

## 常见问题

**首次充值后买不了服务器？**
大概率是碰上了 24 小时的新账户验证期，等一天再试。

**SSH 一直连不上怎么办？**
先确认部署完成已超过 5 分钟。还不行，多半是这台机器的 IP 有问题，按上一节的顺序换一台。

**会不会乱扣费？**
计费按小时走，Billing 里每一笔都有流水可查。真正多花钱的情况只有一种：不用的机器只关机不删除。

**自己充的钱会过期吗？**
不会。有过期时间的是活动赠金，一般 30 天到一年不等，以活动说明为准。

**支持哪些付款方式？**
支付宝、PayPal、信用卡都支持。部分新客赠金活动有支付方式限制，参加前看清楚条款。
